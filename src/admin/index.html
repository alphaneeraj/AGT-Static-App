GitHub connection

Blog posts are saved as files in . Create a fine-grained token limited to this repository with Contents: Read and write and Actions: Read and write.

Admin access

Admins sign in with Supabase accounts. To add one, create the user in Supabase → Authentication, then run insert into admins (email) values ('name@example.com'); in the SQL editor.
